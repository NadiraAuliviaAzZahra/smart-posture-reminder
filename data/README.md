# Data eksperimen

Folder ini berisi template pengukuran kosong. Tambahkan **hanya hasil eksperimen nyata** setelah kalibrasi/pengujian selesai. Jangan mengunggah data pribadi subjek atau informasi yang belum diizinkan untuk publikasi.

Kolom CSV: `axis,reference_deg,mpu_deg,repeat` dengan `axis` bernilai `pitch` atau `roll`.
