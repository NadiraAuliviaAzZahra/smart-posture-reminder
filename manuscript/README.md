# Rencana manuskrip ilmiah

**Judul sementara:** *Design and Performance Evaluation of an MPU6050–ESP32 Wearable Posture Reminder*.

Kontribusi yang ditargetkan:
1. Rancangan perangkat pemantauan kemiringan tubuh berbasis MPU6050 dan ESP32.
2. Implementasi peringatan getar setelah deviasi melebihi 15° selama 3 detik.
3. Evaluasi akurasi sudut dan pengujian kinerja melalui alat pembanding.
4. Analisis keandalan sistem serta keterbatasannya.

Target jurnal yang direncanakan: Electrician: Jurnal Rekayasa dan Teknologi Elektro.

**Belum ada hasil eksperimen yang boleh diklaim.** Manuskrip final disusun setelah pengujian dan analisis selesai.
